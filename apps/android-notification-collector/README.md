# Android 거래 알림 수집기

카드사 앱 알림 중 금액(`원`)과 금융 키워드가 함께 있는 알림을 가계부의 자동등록 대기함으로 전송하는 최소 Android 앱입니다.

## 빌드

1. Android Studio에서 이 디렉터리를 엽니다.
2. Android SDK 35를 설치합니다.
3. `Build > Build APK(s)`를 실행합니다.
4. 생성된 `app/build/outputs/apk/debug/app-debug.apk`를 Android 기기에 설치합니다.

## 연결

1. 가계부 웹의 `환경설정 > 자동등록`에서 기기 연결 토큰을 발급합니다.
2. 앱에 운영 주소와 토큰을 입력하고 저장합니다.
3. `알림 접근 권한 열기`에서 이 앱의 접근을 허용합니다.
4. 테스트 알림을 보내고 웹의 자동등록 대기함에서 수신 여부를 확인합니다.

토큰은 Android 기기에만 저장되며 서버에는 SHA-256 해시로 저장됩니다. 알림 원문은 서버에서 AES-256-GCM으로 암호화됩니다.
